Connect to Peer (e.g. Kubo Desktop)

Browser nodes can only dial WebSocket transports (/ws or /wss). Replace <KUBO_PEER_ID> with the peer ID from your Kubo node.

Connection Help

Browsers cannot open raw TCP or UDP sockets. This Helia node can only dial peers over /ws, /wss, WebTransport, or WebRTC-direct addresses.

If you see "Connection failed: The dial request has no valid addresses", Kubo is probably not listening on a browser-compatible transport.

Quick setup with npm commands

From this repo, run on the machine hosting Kubo:

# 1. Plain WebSocket (works for local HTTP dev)
npm run kubo:ws
ipfs daemon
# Dial: /ip4/127.0.0.1/tcp/4002/ws/p2p/<KUBO_PEER_ID>

Option A: Native Kubo WSS (public nodes)

Kubo can automatically obtain a TLS certificate via AutoTLS. The resulting address uses a *.libp2p.direct domain, so this only works for publicly reachable nodes.

npm run kubo:wss
ipfs daemon
# After the node is online, look for an address like:
# /dns4/<PEER_ID>.libp2p.direct/tcp/443/wss/p2p/<PEER_ID>

Option B: Reverse-proxy WSS (LAN / custom domain)

For local IPs like 192.168.1.74 or your own domain, Kubo cannot use a custom certificate natively. Run a local TLS proxy in front of Kubo's /ws listener instead.

# 1. Start Kubo with a plain /ws listener
npm run kubo:ws
ipfs daemon

# 2. In another terminal, generate a cert and start the proxy
npm run cert:generate      # add CERT_SANS=192.168.1.74 if needed
npm run proxy:wss          # listens on wss://0.0.0.0:4003

# 3. Dial the proxy:
# /ip4/192.168.1.74/tcp/4003/wss/p2p/<KUBO_PEER_ID>

To include a LAN IP in the self-signed certificate, run:

CERT_SANS=192.168.1.74 npm run cert:generate

Which addresses work from a browser?

  • Works: /ip4/127.0.0.1/tcp/4002/ws/p2p/...
  • Works: /dns4/example.com/tcp/443/wss/p2p/... (HTTPS-proxied Kubo)
  • May work: WebTransport or WebRTC-direct addresses (requires HTTPS except on localhost)
  • Does not work: raw TCP such as /ip4/127.0.0.1/tcp/4001/p2p/...
  • Does not work: QUIC such as /ip4/127.0.0.1/udp/4001/quic-v1/p2p/...

Use ipfs id to see your Kubo peer ID and current addresses.
