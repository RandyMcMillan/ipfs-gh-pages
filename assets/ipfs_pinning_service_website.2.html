Relay Pin Event Publishing

When pinning files through PinPoint, optionally publish a Nostr event (Kind 30063 / Data Item) to announce your IPFS CIDs across decentralised Nostr relays. 

curl -X POST https://api.pinpoint-ipfs.io/v3/pins \
  -H "Authorization: Nostr <NIP-98_BASE64_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "cid": "bafybeigdyrzt5sfp7udm7hu76uh7y26nf3efuylqabf3oclgtqy55fbzdi",
    "name": "My Decentralized Asset",
    "origins": ["/ip4/192.0.2.1/tcp/4001/p2p/QmPeerId"]
  }'
import { PinPointClient } from '@pinpoint/ipfs-sdk';

const client = new PinPointClient({ 
  nostrSigner: window.nostr // NIP-07 extension
});

async function pinContentWithNostr() {
  const response = await client.pins.add({
    cid: 'bafybeigdyrzt5sfp7udm7hu76uh7y26nf3efuylqabf3oclgtqy55fbzdi',
    name: 'My Nostr NFT Asset'
  });
  
  console.log('Nostr Pinned Status:', response.status);
}
